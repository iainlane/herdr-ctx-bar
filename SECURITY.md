# Security Policy

## Supported versions

Until Context Bar reaches a stable release, security fixes are provided for the latest version on the `main` branch.

## Reporting a vulnerability

Please report security issues through [GitHub private vulnerability reporting](https://github.com/pdalinis/herdr-ctx-bar/security/advisories/new). Do not open a public issue for a suspected vulnerability.

Because Context Bar reads local agent session data, redact prompts, responses, credentials, filesystem paths, and other private information from reports and reproduction files. Include only the minimum information needed to reproduce the issue.

You should receive an acknowledgment within seven days. Please allow time to investigate and prepare a fix before publicly disclosing the issue.
